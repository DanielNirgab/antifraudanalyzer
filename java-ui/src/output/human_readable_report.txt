3. Распределение Class
Мошеннические операции составляют только 0.1727%. Это типичная ситуация для антифрод-задач: редкие события нужно находить среди огромного количества нормальных операций.

4. Amount
Сумма операции сама по себе не позволяет надежно отделить мошенничество от обычных операций. Мошеннические операции могут встречаться как среди маленьких, так и среди крупных сумм.

5. Time
Признак Time помогает проверить, есть ли временные закономерности. Если подозрительные операции чаще встречаются в определенные часы, модель может использовать эту информацию.

ИНТЕРПРЕТАЦИЯ РЕЗУЛЬТАТОВ МОДЕЛЕЙ

В проекте обучены три модели:
1. Logistic Regression — базовая линейная модель.
2. Decision Tree — интерпретируемая модель на правилах.
3. Random Forest — ансамбль деревьев, обычно более устойчивый, чем одно дерево.

Расшифровка метрик:
Accuracy — общая доля правильных ответов. В антифроде может быть обманчивой из-за дисбаланса.
Precision — сколько операций, отмеченных моделью как мошеннические, действительно мошеннические.
Recall — какую долю реальных мошеннических операций модель смогла найти.
F1-score — баланс между Precision и Recall.
ROC-AUC — общая способность модели различать обычные и мошеннические операции.

Результаты простыми словами:
- Logistic Regression: Recall=0.918, Precision=0.061, F1=0.114, ROC-AUC=0.972. Модель нашла 90 мошеннических операций и пропустила 8. Ложных тревог: 1386.
- Decision Tree: Recall=0.878, Precision=0.047, F1=0.090, ROC-AUC=0.917. Модель нашла 86 мошеннических операций и пропустила 12. Ложных тревог: 1729.
- Random Forest: Recall=0.847, Precision=0.648, F1=0.735, ROC-AUC=0.982. Модель нашла 83 мошеннических операций и пропустила 15. Ложных тревог: 45.

Лучшая модель по правилу Recall -> F1-score -> ROC-AUC: Logistic Regression.

Почему приоритет отдан Recall:
В антифрод-задаче опаснее пропустить мошенническую операцию, чем дополнительно проверить подозрительную нормальную операцию. Поэтому важнее найти как можно больше мошенничества, но при этом нужно следить за Precision, чтобы не создавать слишком много ложных тревог.

Краткий вывод по лучшей модели:
Logistic Regression обнаружила 90 мошеннических операций из 98 в тестовой выборке. Пропущено 8. Ложных тревог: 1386.
